■ これは何か

Splice などのオーディオサンプルを、Pro Tools の上で MIDI 鍵盤から弾けるように
するアプリです。音源には、無料のサンプラー sforzando（Plogue 社）を使います。
サンプルの並べ方を書いた定義ファイル（SFZ）をこのアプリが作り、sforzando に
読ませるので、サンプラーの画面を目で見て操作する必要がありません。
VoiceOver とキーボードだけで使えるように作っています。
名前の「PT」は Pro Tools のことです。Pro Tools は Avid Technology 社の製品で、
このアプリは Avid Technology 社とは関係ありません。

■ 動く環境

- Apple シリコン（M1 以降）の Mac。macOS 15 以降（作者は 15.7.8 で確かめています）
- Pro Tools（作者は 2026.4.1 で確かめています）
- sforzando の AAX 版（無料。作者は 1.982 で確かめています）
- VoiceOver
- 画面と読み上げは、Mac の言語の設定に合わせて日本語か英語で出ます（マニュアルの 2 章）
- ループの速さを保ったまま鍵盤に広げる機能と、テンポを合わせる機能には
  ffmpeg が要ります（Homebrew で入れます）。rubberband もあれば、音質が上がります

■ 入れ方（短く）

1. このフォルダの「PT SFZビルダー.app」を、アプリケーションフォルダへ移します
2. 開きます。初めて開くとき、macOS が開くのを止めることがあります。
   開き方は、マニュアルの「3.2 初めて開くとき」にあります
3. 操作メニューの「アクセシビリティの設定を開く」で、PT SFZビルダー をオンにします
   （マニュアルの「3.3 許可を入れる」）
4. Pro Tools で、インストゥルメントトラックに sforzando を挿し、その画面を開きます
5. コマンド+R で Splice の索引を作り、素材を探して、一覧でリターンを押します。
   そのトラックで初めて割り当てたときだけ、「プラグインに読み込ませる」を押します

詳しくは「マニュアル.html」（または「マニュアル.txt」）を読んでください。
アプリの中では、コマンド+シフト+K でキー操作の一覧を開けます。
