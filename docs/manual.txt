■ 1. このアプリでできること

Splice などのオーディオサンプルを、Pro Tools の上で MIDI 鍵盤から弾けるようにするアプリです。VoiceOver とキーボードだけで使えるように作っています。
音源には、無料のサンプラー sforzando（Plogue 社）を使います。サンプルの並べ方を書いた定義ファイル（SFZ という形式）をこのアプリが作り、sforzando に読ませます。サンプラーの画面を目で見て操作する必要がありません。
・Splice の素材を、語・キー・BPM・種別（ワンショット・ループ・効果音）・パックで探します
・一覧でスペースを押すと試聴、リターンを押すと、前に出ている sforzando に割り当てます
・並べ方は 3 つあります。1 つの音を鍵盤全体に広げる、ループの速さを保ったまま鍵盤に広げる、選んだ音を 1 鍵盤に 1 つずつ並べる（ドラムキット）、です。初めの設定では、素材に合わせてアプリが選びます
・素材のテンポを、Pro Tools のセッションのテンポに合わせられます
・音の立ち上がりや余韻（ADSR）と、こもらせるフィルターを、5 つの組み合わせから選べます

結果は VoiceOver が読み上げます。時間のかかる操作は、始まりと終わりを短い音でも知らせます。

■ 3. 入れ方

◆ 3.1 アプリを置く

1. 受け取った zip ファイルを Finder で開きます（選んでコマンド+O）。同じ場所に「PT SFZビルダー_1.0.1」というフォルダができます
2. フォルダの中の「PT SFZビルダー.app」を、アプリケーションフォルダへ移します。Finder で .app を選んでコマンド+C、アプリケーションフォルダでオプション+コマンド+V（移動）です
3. マニュアルなどの文書は、どこに置いてもかまいません

◆ 3.2 初めて開くとき

このアプリは、Apple による公証（ノータリゼーション）を受けていません。そのため、インターネットから受け取った zip から取り出したアプリを初めて開くと、macOS が開くのを止めることがあります。そのときは、次のどちらかで開きます。

・方法 1: システム設定から開く

1. アプリを一度開こうとします。開けないという知らせが出たら、「完了」で閉じます
2. システム設定の「プライバシーとセキュリティ」を開き、下のほうの「セキュリティ」へ進みます。PT SFZビルダー の使用がブロックされたという文と、「このまま開く」のボタンがあります
3. 「このまま開く」を押し、パスワード（または Touch ID）で認めます
4. もう一度アプリを開き、確かめる知らせが出たら「このまま開く」を選びます

macOS の版によって、文やボタンの名前が少し違うことがあります。2 回目からは、ふつうに開けます。

・方法 2: ターミナルで隔離の印を外す

アプリをアプリケーションフォルダへ移してから、ターミナルで次の 1 行を実行します。
xattr -dr com.apple.quarantine "/Applications/PT SFZビルダー.app"
インターネットから受け取ったファイルに付く「隔離」の印を外す命令です。外したあとは、ふつうに開けます。

◆ 3.3 許可を入れる（アクセシビリティとオートメーション）

このアプリは、Pro Tools のプラグインの画面を読み（どのトラックのどのプラグインか）、sforzando の画面を押して定義ファイルを読ませます。そのために、2 つの許可が要ります。許可は、ご自身で入れてください。
1. アクセシビリティ: 操作メニューの「アクセシビリティの設定を開く」を選ぶと、システム設定の「プライバシーとセキュリティ」→「アクセシビリティ」が開きます。一覧の「PT SFZビルダー」をオンにします。一覧に無いときは、一覧の下の「追加」のボタン（＋）で、アプリケーションフォルダの PT SFZビルダー.app を選びます
2. オートメーション（System Events）: 初めて Pro Tools の画面を読むとき、「“PT SFZビルダー”が“System Events”を制御するアクセスを要求しています」と聞かれます。「許可」を選びます。断ってしまったときは、システム設定の「プライバシーとセキュリティ」→「オートメーション」で、PT SFZビルダー の中の「System Events」をオンにします

許可が無いと、「割り当て先を調べる」のボタンの名前や読み上げで、どこで何をオンにすればよいかを言います。許可を入れたら、アプリを開き直します。

・新しい版に入れ替えたとき

このアプリは開発者の証明書で署名していないため、新しい版に入れ替えると、macOS は別のアプリとみなします。アクセシビリティの一覧で PT SFZビルダー をいったん外し（一覧で選んで、下の「削除」のボタン（－））、もう一度入れてください。
書類・デスクトップ・ダウンロードのフォルダや、外付けのドライブにあるファイルを選んで割り当てると、「PT SFZビルダー が … のファイルへのアクセスを求めています」と聞かれることがあります。「許可」を選びます。

◆ 3.4 sforzando を入れる

1. Plogue 社のページ（https://www.plogue.com/products/sforzando.html）から、macOS 版を入れます。Pro Tools で使うので、AAX 版を入れます
2. Pro Tools のセッションにインストゥルメントトラックを作り、インサートに sforzando を挿します
3. sforzando のプラグインの画面を開いておきます。このアプリは、開いている sforzando の画面を見て、割り当て先を決めます

sforzando の画面は、VoiceOver では読めません。読ませる操作は、このアプリが代わりに行います（10 章）。

◆ 3.5 ffmpeg と rubberband（ループの速さを保つとき）

ループの速さを保ったまま鍵盤に広げるとき（9.2）と、セッションのテンポに合わせるとき（9.4）は、音程を変えずに長さを変えたファイルを作ります。そのために ffmpeg を使います。rubberband もあれば、そちらを使い、音質が上がります。どちらも Homebrew で入れます。ターミナルで次の 1 行を実行します。
brew install ffmpeg rubberband
アプリは、Homebrew の置き場所（/opt/homebrew/bin と /usr/local/bin）から探します。入れたあとは、アプリを開き直します。ワンショットを鍵盤全体に広げるだけ、ドラムキットを組むだけなら、どちらも要りません。

■ 4. はじめに: Splice の索引を作る

アプリを開くと、検索語の欄にフォーカスがあります。Splice の素材を検索で探すには、先に素材の一覧（索引）を作ります。
1. コマンド+R（操作メニューの「Splice の索引を更新」）を押します。「索引を更新しています。終わったらお知らせします。」と読み上げます
2. 終わると、件数を読み上げます（「索引を更新しました。3127 件。うち 3127 件を読み直しました。」のように）。初めて作るときは、素材の数によって数十秒かかることがあります。その間もアプリは操作できます

Splice のフォルダは、ふつうはホームフォルダの Splice の中の sounds の中の packs です。Splice のアプリの設定で場所を変えているときは、操作メニューの「Splice のフォルダを選ぶ」で選び直します。Splice のフォルダそのものを選んでもかまいません（中の sounds/packs を使います）。選ぶと、そのフォルダで索引を作り直します。
素材を買い足したら、もう一度コマンド+R を押します。前の索引から変わっていない素材は読み直さないので、2 回目からは 1 秒ほどで終わります。
Splice を使っていなくても、操作メニューの「ファイルを選んで割り当て」で、手元の音を割り当てられます（9.6）。

■ 5. 使い方の流れ

1. Pro Tools で、インストゥルメントトラックに sforzando を挿し、その sforzando の画面を開いておきます
2. このアプリで素材を探し（7 章）、検索結果一覧でスペースを押して試聴します（8 章）
3. 決めたら、一覧でリターンを押します。前に出ている sforzando の画面を見て、そのトラックに割り当てます。結果を読み上げます（「配置は「鍵盤全体に広げる」にしました。 スフォルツァンド スロット1に BOS_ADJ_Bass_Synth_One_Shot_Heya_F.wav、ルートキーF3、全鍵盤 を割り当てました。トラック「Inst1」。 書き込みました。自動で反映されます。 ルートキー F3。ファイル名のFから決めました。」のように）
4. そのトラックで初めて割り当てたときだけ、「プラグインに読み込ませる」のボタンを押します（10 章）。10 秒ほどかかります
5. MIDI 鍵盤で弾いて確かめます
6. 次の素材を選んで、リターンを押します。2 回目からは、割り当てるだけで sforzando の音が変わります（sforzando が定義ファイルの置き場所を見張っていて、書き換えると自動で読み直すためです）

トラックを増やすときは、別のインストゥルメントトラックに sforzando を挿し、その画面を開いてから割り当てます。トラックごとに別のスロット（定義ファイル）を使います（11 章）。

主画面でタブを押したときに止まる場所を、止まる順に並べました。名前は VoiceOver が読む名前の最初の文です。シフト+タブで逆の順に戻ります。表は 13 行で、列は「順」「読み上げられる名前」「種類」の 3 つです。

・順: 2 / 読み上げられる名前: キー / 種類: 選択肢
・順: 3 / 読み上げられる名前: 平行調も含める / 種類: チェック
・順: 4 / 読み上げられる名前: BPM / 種類: 入力欄
・順: 5 / 読み上げられる名前: 種別 / 種類: 選択肢
・順: 6 / 読み上げられる名前: パック / 種類: 選択肢
・順: 7 / 読み上げられる名前: 検索を実行 / 種類: ボタン
・順: 8 / 読み上げられる名前: 検索結果一覧 / 種類: 一覧
・順: 9 / 読み上げられる名前: 割り当ての設定 / 種類: ボタン
・順: 10 / 読み上げられる名前: 割り当てを実行 / 種類: ボタン
・順: 11 / 読み上げられる名前: プラグインに読み込ませる / 種類: ボタン
・順: 12 / 読み上げられる名前: ファイルを選んで割り当て / 種類: ボタン
・順: 13 / 読み上げられる名前: 割り当て先を調べる / 種類: ボタン

ボタンにタブで止まるのは、macOS の「キーボードナビゲーション」が入っているときです（システム設定の「キーボード」）。VoiceOver の移動（VO+右矢印）なら、いつでもたどれます。ボタンはリターンでもスペースでも押せます。
ボタンの名前には、いまの状態が入っています。「割り当ての設定。いまは 素材に合わせる、テンポは素材のまま」「割り当て先を調べる。いまは トラック「Inst1」のスフォルツァンド。セッションは「261024_1」です。」「プラグインに読み込ませる。いま必要です」のように読みます。いちばん下の状態の表示には、最後の結果の文が出ています。

■ 7. 探す

◆ 7.1 検索の条件

欄を入れて、検索語か BPM の欄でリターンを押すか、「検索を実行」を押します。見つかった数と、何で絞ったかを読み上げます（「1 件見つかりました。語「bass」。」のように）。0 件なら低い音を鳴らします。条件はすべて同時に満たすものを探します（かつ）。
・検索語: ファイル名・パックの名前・説明のどこかに含まれるものを探します。空白で区切って複数の語を入れると、全部を含むものだけになります。大文字と小文字は区別しません。日本語入力のまま全角で打っても見つかります
・キー: ファイル名に書かれたキーで絞ります。「平行調も含める」を入れると、平行調（A マイナーなら C メジャー）も含めます
・BPM: ファイル名に書かれた BPM で絞ります。前後 4 の範囲を含めます。空欄なら指定しません
・種別: ワンショット・ループ・効果音
・パック: Splice のパックです。そのパックの素材だけになります

◆ 7.2 種別の決め方

種別は、長さを先に見ます。2 秒を超える音はループとみなします（ファイル名が何であっても）。2 秒以下の音は、ファイル名の判定（one shot・loop などの語）に従います。効果音（fx）は、長さで言い換えません。一覧の種別も、この決め方で読みます。

◆ 7.3 パックの並び順

コマンド+シフト+G で、パックの欄の並び順を順に切り替えます。表は 4 行で、列は「並び」「向き」「使いどころ」の 3 つです。
・並び: 中身の多い順（初め） / 向き: 多い順 / 使いどころ: 目当てが決まっていないとき
・並び: 名前順 / 向き: アルファベット順 / 使いどころ: 名前を覚えているとき。頭文字で飛べます
・並び: 更新の新しい順 / 向き: 新しい順 / 使いどころ: 最近さわったパックを探すとき
・並び: 追加した順 / 向き: 古い順 / 使いどころ: 入れた順にたどるとき

選んだ並び順は覚えていて、次に開いたときも同じです。パックの欄で選んでいたパックは、並べ替えても選んだままです。

◆ 7.4 検索結果一覧

上下矢印で素材を移ります。文字キーを押すと、その頭文字の素材へ飛びます。コマンド+I で、どこからでも一覧へ戻れます。一覧に移ったとき何も選ばれていなければ、先頭を選びます。
コマンド+C で、選んでいる素材のパスをコピーします。検索語などの文字入力欄にいるときは、選んだ文字のコピーになります。

■ 8. 試聴する

検索結果一覧でスペースを押すと、選んでいる素材を鳴らします。もう一度押すと止まります。鳴っている間に別の素材でスペースを押すと、そちらに切り替わります。割り当てるときは、試聴を止めてから割り当てます。

■ 9. 割り当てる

◆ 9.1 割り当て先

割り当てる先は、Pro Tools で開いている sforzando の画面のトラックです。リターンを押すたびに調べ直すので、割り当てたいトラックの sforzando の画面を開いてから押します。コマンド+T（「割り当て先を調べ直す」）で、いまの割り当て先を確かめられます。Pro Tools は後ろにあってもかまいません。
プラグインの画面がいくつか開いているときは、いちばん前の sforzando の画面を使います。sforzando の画面が開いていないと、「プラグインのウィンドウが開いていません」と言って割り当てません。

◆ 9.2 配置（並べ方）

コマンド+S の「割り当ての設定」で選びます。表は 4 行で、列は「配置」「並べ方」「向いている素材」の 3 つです。
・配置: 素材に合わせる（初め） / 並べ方: 割り当てるときに、次の 3 つから選びます。ループなら「速さを保つ」、2 個以上選んだら「1鍵盤に1サンプル」、それ以外は「鍵盤全体に広げる」。選んだ配置を読み上げます / 向いている素材: 迷ったとき
・配置: 鍵盤全体に広げる / 並べ方: 1 つの音を、すべての鍵盤に広げます。ルートキーの鍵盤で元の高さが鳴り、離れるほど高さと一緒に速さも変わります / 向いている素材: ワンショット
・配置: 鍵盤全体に広げる。速さを保つ / 並べ方: 鍵盤ごとに、あらかじめ長さを変えたファイル（下ごしらえ）を作ります。どの鍵盤でも元の速さで、高さだけが変わります。ルートキーから上下に、選んだ範囲（初めは 1 オクターブ、25 鍵盤）だけ鳴ります / 向いている素材: ループ・フレーズ
・配置: 1鍵盤に1サンプル / 並べ方: 選んだ音を、C1 から半音ずつ上へ 1 つずつ並べます。鍵盤を離しても最後まで鳴ります / 向いている素材: ドラムキット

「速さを保つ」は、下ごしらえのファイルを作る間、数秒かかります。始める前に「25鍵盤ぶんの下ごしらえをしています。少しお待ちください。」と言います。同じ素材を同じ範囲で割り当て直すときは、作り直しません。下ごしらえは、13 秒ほどのステレオの素材で 1 回あたり 90 メガバイトほどになります（12 章）。

◆ 9.3 ルートキー

ルートキーは、元の高さで鳴る鍵盤です。初めの設定（自動）では、ファイル名のキー（Amin・F など）から決めます。読めなかったときは C3 にして、「キーを推定できなかったので既定値です。鳴らして確かめ、必要なら変えてください。」と言います。どう決めたかは、割り当てるたびに言います。
音名は、中央のドを C3（MIDI の 60 番）と数えます（Pro Tools と同じ数え方）。ファイル名のキーにはオクターブが無いので、C3 から B3 の範囲に置きます。違うときは、割り当ての設定でルートキーとオクターブを選びます。ドラムキットでは、ルートキーは使いません。

◆ 9.4 セッションのテンポに合わせる

割り当ての設定の「セッションのテンポ」に数（20 から 400）を入れると、素材の長さを変えて、そのテンポで鳴るようにします。素材の元のテンポは、ファイル名から読みます（_145_ や 120bpm のような書き方）。読めなかった素材は変えず、そう言います。空欄なら、素材のテンポのままです。
・入れたテンポは、Pro Tools のセッションごとに覚えます。セッションを開き直すと、そのセッションの値に戻ります
・「倍・半分のテンポの解釈を許す」が入っていると、伸び縮みが 1.5 倍を超えるときに、元のテンポを倍や半分とみなします。170 BPM の素材を 85 BPM のセッションでそのまま使えます
・1.5 倍を超えて伸び縮みするときは、音が荒れることがあると言います
・「鍵盤全体に広げる」では、テンポが合うのはルートキーの鍵盤だけです（そう言います）。どの鍵盤でも合わせたいときは「速さを保つ」にします
・「1鍵盤に1サンプル」では、素材ごとにテンポを合わせます。ワンショットは変えません

◆ 9.5 音作り

割り当ての設定の「音作り」で、5 つの組み合わせから選びます。表は 5 行で、列は「音作り」「中身」の 2 つです。
・音作り: そのまま（初め） / 中身: すぐに鳴り始め、離すと 0.08 秒で消えます。フィルターなし
・音作り: やわらかい立ち上がり / 中身: 0.15 秒かけて鳴り始め、離すと 0.3 秒で消えます
・音作り: 短く切る / 中身: 0.12 秒で消えていきます（押さえていても伸びません）
・音作り: こもらせる / 中身: 800 ヘルツから上を削ります（ローパス、12dB/oct）
・音作り: ワンショット / 中身: 離すと 0.02 秒で消えます

これより細かい音作りは、Pro Tools 側のプラグインで行う前提です。

◆ 9.6 ファイルを選んで割り当てる

操作メニューの「ファイルを選んで割り当て」（または同じ名前のボタン）で、Splice の外の音も割り当てられます。WAV・AIFF・FLAC・OGG を選べます。いくつか選ぶと、「素材に合わせる」では「1鍵盤に1サンプル」（ドラムキット）になります。ファイルを選ぶ画面では、シフト+上下矢印で続けて選べます。コマンド+A で、そのフォルダの全部を選べます。

◆ 9.7 割り当ての設定の項目（コマンド+S）

コマンド+S の「割り当ての設定」の画面に並ぶ項目です。タブで止まる順に、VoiceOver が読む名前の最初の文と、アプリを初めて開いたときの値を書きました。表は 9 行で、列は「読み上げられる名前」「種類」「初めの値」の 3 つです。
・読み上げられる名前: 配置 / 種類: 選択肢 / 初めの値: 素材に合わせる
・読み上げられる名前: 速さを保つときの範囲 / 種類: 選択肢 / 初めの値: 上下1オクターブ。25鍵盤
・読み上げられる名前: セッションのテンポ / 種類: 入力欄 / 初めの値: 空欄
・読み上げられる名前: 倍・半分のテンポの解釈を許す / 種類: チェック / 初めの値: 入れる
・読み上げられる名前: ルートキー / 種類: 選択肢 / 初めの値: 自動
・読み上げられる名前: オクターブ / 種類: 選択肢 / 初めの値: 3
・読み上げられる名前: 音作り / 種類: 選択肢 / 初めの値: そのまま
・読み上げられる名前: 取り消し / 種類: ボタン / 初めの値: 値なし
・読み上げられる名前: 決定 / 種類: ボタン / 初めの値: 値なし

リターンで決定して閉じます（取り消しのボタンの上では、取り消しになります）。エスケープかコマンド+W で、何も変えずに閉じます。決定すると、いまの設定を読み上げ、「割り当ての設定」のボタンの名前にも入ります。

■ 10. sforzando に読み込ませる（スロットごとに初めの 1 回）

割り当ては、そのトラック用の定義ファイル（スロット）を書くだけです。そのトラックの sforzando に、初めて割り当てたときだけ、sforzando にそのファイルを読ませる操作が要ります。一度読ませれば、あとは割り当てるたびに sforzando が自動で読み直します。
1. 割り当てたトラックの sforzando の画面を、Pro Tools で開いておきます
2. 「プラグインに読み込ませる」のボタン（または操作メニューの同じ項目）を押します。「プラグインに読み込ませています。10秒ほどかかります。」と言います
3. アプリが Pro Tools を前に出し、sforzando の画面を押して、ファイルを選ぶ画面にファイルの場所を入れます。その間、キーボードとマウスにさわらないでください
4. 終わるとこのアプリに戻り、「トラック「Inst1」のスフォルツァンドに読み込ませました。」のように言います

要るかどうかは、ボタンの名前で分かります（「いま必要です」「いまは必要ありません」）。sforzando の記録を読んで決めています。必要ないときはボタンが押せなくなりますが、操作メニューの項目からはいつでも押せます（Pro Tools を開き直したあとなど、念のため読み直したいとき）。

◆ 安全のためにしていること

・押すのは、割り当てたトラックの sforzando の画面だけです。別のトラックの画面しか開いていないときは押さず、どのトラックの画面を開けばよいかを言います
・その画面をいちばん前に出し、前に出たことを確かめてから押します。押す位置が画面の外になるときは押しません
・sforzando の版が、作者が確かめた版と違って画面の作りが変わっているときは、押しません（「sforzando の版が、このアプリで確かめた版と違うようです」と言います）
・sforzando がエラーの知らせ（サンプルが見つからないなど）を出したままだと、押しても効きません。押す前に、その知らせを閉じます
・ファイルの場所はクリップボードを通して入れます。クリップボードの中身は、終わったら元に戻します（文字のときだけです。画像などは戻りません）

■ 11. スロットと Pro Tools のセッション

定義ファイルを「スロット」と呼びます。トラックの名前ごとに 1 つのスロットを使い、同じトラックに割り当て直すと、同じスロットを書き換えます。1 つのセッションで 16 トラックまで使えます。
スロットは、Pro Tools のセッションごとに別のフォルダに置きます。Pro Tools は、新しいセッションでも Inst1 のような同じトラックの名前を付けるので、分けないと、別のセッションで割り当てたときに前のセッションの音を書き換えてしまうためです。セッションの名前は、Pro Tools の編集ウインドウかミックスウインドウの名前から読みます。
コマンド+シフト+L で、いまのセッションで使っているスロットを読み上げます（「セッション「261024_1」。1 スロットを使っています。スロット1、Inst1、Vocal_Chop_7.wav、ルートキーC3、全鍵盤。」のように）。

◆ sforzando はファイルの場所だけを覚えています

Pro Tools のセッションに保存されるのは、定義ファイルの場所だけで、中身ではありません。セッションを開き直すと、その時点でファイルにある音が鳴ります。アプリの置き場所（15 章）のファイルを動かしたり消したりしないでください。そのファイルを使っているセッションで、音が鳴らなくなります。

■ 12. 下ごしらえを片付ける

「速さを保つ」とテンポ合わせで作った下ごしらえのファイルは、たまっていきます。操作メニューの「使っていない下ごしらえを片付ける」で、どのセッションのスロットも使っていないものを消せます。
1. 選ぶと、使っていないファイルの数と大きさを読み上げ、「消してよいですか」と聞きます
2. 「はい」で消し、消した数と空いた大きさを言います。「いいえ」なら何もしません

消す直前にもう一度数え、そのあいだに使い始めたものは消しません。読めない定義ファイルが 1 つでもあるときは、要るファイルを消さないよう、片付けをやめます。

■ 14. 通知の音と読み上げ

読み上げの前に短い音で知らせます。表は 3 行で、列は「場面」「音」の 2 つです。

■ 16. 困ったとき

◆ 「プラグインウィンドウを調べられませんでした。…許可がありません」と言われる

言われたとおりに、システム設定でアクセシビリティかオートメーションをオンにします（3.3）。新しい版に入れ替えたあとは、アクセシビリティの一覧でいったん外して、入れ直します。

◆ 「プラグインのウィンドウが開いていません」「割り当て対象のプラグインではありません」と言われる

Pro Tools で、割り当てたいトラックの sforzando の画面を開きます。sforzando 以外のプラグイン（Decent Sampler など）には割り当てられません。

◆ 「Pro Tools が起動していません」と言われる

Pro Tools を開き、セッションを開いてから、コマンド+T で調べ直します。

◆ 割り当てても音が変わらない

そのトラックの sforzando に、まだ読ませていないかもしれません。「プラグインに読み込ませる」を押します（10 章）。ボタンの名前が「いま必要です」なら、読み込ませる必要があります。

◆ 「ffmpeg も rubberband も入っていません」と言われる

3.5 のとおりに Homebrew で ffmpeg を入れ、アプリを開き直します。ワンショットなら、配置を「鍵盤全体に広げる」にすれば ffmpeg 無しで割り当てられます。

◆ 「sforzando の版が、このアプリで確かめた版と違うようです」と言われる

sforzando の画面の作りが、作者が確かめた版（1.982）と違うため、押す位置が合いません。安全のため、読み込ませる操作をしません。作者に知らせてください。

◆ 「Splice の索引がまだ無いか、読めません」と言われる

コマンド+R で索引を作ります（4 章）。「Splice のフォルダが見つかりません」と言われたら、操作メニューの「Splice のフォルダを選ぶ」で選び直します。

◆ 鳴る高さが違う

ルートキーがファイル名から読めなかったか、オクターブが違います。割り当ての設定（コマンド+S）でルートキーとオクターブを選び、割り当て直します（9.3）。

◆ 「速さを保つ」で、端の鍵盤が鳴らない

用意する範囲の外は鳴りません。割り当ての設定の「速さを保つときの範囲」を広げて（上下 2 オクターブまで）、割り当て直します。

◆ 読み上げが聞こえない

VoiceOver が入っているかを確かめます。いちばん下の状態の表示に、最後の結果の文が出ています。

◆ それでも分からないとき

記録（~/Library/Logs/SfzBuilder.log）に、アプリが起動した日時と、出たエラーが残っています。

■ 17. 取り除き方

1. アプリを終了し（コマンド+Q）、アプリケーションフォルダの「PT SFZビルダー.app」をゴミ箱へ入れます
2. アクセシビリティとオートメーションの一覧から、PT SFZビルダー を外します
3. スロットと設定を消すなら、~/Music/SFZBuilder をゴミ箱へ入れます。ただし、そのスロットを使っている Pro Tools のセッションでは、音が鳴らなくなります（11 章）。記録は ~/Library/Logs/SfzBuilder.log です

■ 18. できないこと・気をつけること

・Intel の Mac では動きません
・割り当てられるのは sforzando だけです。Decent Sampler などには割り当てられません
・sforzando に読み込ませる操作は、sforzando の画面の決まった位置を押して行います。作者が確かめた版（1.982）と画面の作りが違えば、押しません
・読み込ませる操作の間（10 秒ほど）は、キーボードとマウスにさわらないでください。Pro Tools が前に出ます
・ルートキーのオクターブは、ファイル名からは決められません。C3 の範囲に置くので、違うときは選び直します
・素材の BPM とキーは、ファイル名から読みます。名前に書かれていない素材は、テンポを合わせられません
・「速さを保つ」は、用意した範囲の外の鍵盤では鳴りません。伸ばすほど音が荒れ、1 オクターブを超えると分かる程度になります
・セッションの名前が読めないとき（編集ウインドウとミックスウインドウが閉じているとき）は、スロットを全部のセッションで共有する場所に置きます。そのときは、別のセッションの同じ名前のトラックの音を書き換えることがあります
・同じセッションで、同じ名前のトラックを 2 つ作らないでください。トラックの名前でスロットを決めています
・文字入力欄で、取り消し（コマンド+Z）は使えません（画面の部品の作りによるものです）
・割り当てたあとに Pro Tools のテンポを変えても、追いかけません。テンポを入れ直して、割り当て直します
・コマンド+シフト+L で読むスロットの説明は、割り当てたときの言語のままです
